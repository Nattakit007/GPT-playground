## Run locally

Serve `dist/` with any static web server, for example `python3 -m http.server 4173 --directory dist`.

Edit page content in `dist/index.html`, styles in `dist/styles.css`, and interactions in `dist/app.js`. Theme preference is stored only in the visitor’s browser. Project filters and clipboard interaction need no backend.
